# DAMA — Шашки нового поколения

Премиальная веб-платформа для русских шашек с AI-соперником, мультиплеером и детским режимом.

## Для кого

- 🎮 Любители шашек — играй против AI или друга
- 🌟 Дети — обучающий раздел с уроками
- 🏆 Соревнующиеся — глобальный рейтинг по городам
- 🎨 Ценители дизайна — 6 уникальных анимированных скинов

## Технологии

- **Frontend:** React + Vite, Tailwind, shadcn/ui
- **Backend:** Express, Drizzle ORM, PostgreSQL
- **Auth:** Clerk
- **AI:** Minimax + alpha-beta отсечение
